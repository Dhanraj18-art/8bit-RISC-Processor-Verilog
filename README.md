8-bit RISC Processor Design using Verilog

Overview
This project implements an **8-bit RISC (Reduced Instruction Set Computer) processor** using **Verilog HDL**. The processor follows a **single-cycle architecture** and demonstrates fundamental concepts of **CPU microarchitecture, RTL design, and digital system design**.

The design includes core components such as the **Program Counter, Instruction Memory, Register File, Arithmetic Logic Unit (ALU), and Control Unit**. The processor fetches, decodes, and executes instructions within a single clock cycle.

Processor Architecture

The processor is composed of the following modules:

- **Program Counter (PC)** – Holds the address of the next instruction.
- **Instruction Memory** – Stores instructions to be executed.
- **Instruction Decoder** – Extracts opcode and operands from instruction.
- **Register File** – Contains general-purpose registers used for computation.
- **Arithmetic Logic Unit (ALU)** – Performs arithmetic and logical operations.
- **Control Unit** – Generates control signals based on instruction opcode.
- **Datapath** – Connects all modules to perform instruction execution.

Instruction Flow:

1. Instruction Fetch
2. Instruction Decode
3. Execute
4. Write Back


ALU Operations

The ALU supports basic arithmetic and logical operations such as:

- ADD
- SUB
- AND
- OR

Operations are selected using the **ALUOp control signal** generated by the control unit.

Control Unit

The control unit is implemented using **hardwired combinational logic**.  
It decodes the **opcode field of the instruction** and generates control signals including:

- RegWrite
- MemRead
- MemWrite
- ALUSrc
- ALUOp

Verification

The processor design was verified using a **Verilog testbench**.  
Simulation waveforms were analyzed to confirm correct instruction execution and register updates.
